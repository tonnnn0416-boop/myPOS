จุดประสงค์การเรียนรู้ 1. วิเคราะห์ขั้นตอนการทำงานของโปรแกรมจากโจทย์ปัญหาที่กำหนดให้ 2. เขียนรหัสเทียม (Pseudocode) และผังงาน (Flowchart) เพื่อแก้ปัญหาทางธุรกิจเบื้องต้นได้ 3. ปฏิบัติงานร่วมกับผู้อื่นด้วยความรับผิดชอบและตรงต่อเวลา คำชี้แอง ให้นักเรียนวิเคราะห์โจทย์ปัญหาที่กำหนดให้ และแสดงขั้นตอนการแก้ปัญหา (Algorithm) ออกมาในรูปแบบรหัสเทียมและผังงานให้สมบูรณ์ ตอนที่ 1: พบทวนสัญลักษณ์พังงาน (Flowchant) จงจับคู่หรือเติมชื่อและหน้าที่ของสัญลักษณ์ผังงานต่อไปนี้ให้ถูกต้อง (อ้างอิงมาตรฐาน ANSI) 1. สัญลักษณ์: วงรีขอบมน (Terminal) หน้าที่การทำงาน: - ใช้แสดง จุดเริ่มต้น (Start) และจุดสิ้นสุด (End) ของผังงาน 2. สัญลักษณ์: สี่เหลี่ยมด้านขนาน (Input/Output) หน้าที่การทำงาน: - ใช้แสดง การรับข้อมูลเข้าและการแสดงผลข้อมูลออก 3. สัญลักษณ์: สี่เหลี่ยมขนมเปียกปูน (Decision) หน้าที่การทำงาน: - ใช้แสดง การตัดสินใจหรือการตรวจสอบเงื่อนไข เช่น จริง/เท็จ (True/False) 4. สัญลักษณ์: สี่เหลี่ยมผืนผ้า (Process) หน้าที่การทำงาน: - ใช้แสดง ขั้นตอนการประมวลผลหรือการทำงาน ตอนที่ 2: การออกแบบอัลกอริทัมเพื่อแก้ปัญหาทางธุรกิจ โจทย์สถานการณ์ที่ 1: ระบบคิดเงินและส่วนลดร้านสะดวกซื้อ รายละเอียล: ร้านสหกรณ์วิทยาลัย ต้องการโปรแกรมดำนวณราคาสินค้า โดยมีเงื่อนไขว่า ให้ผู้ใช้ป้อนข้อมูลราคาสินค้าต่อชิ้น และจำนวนชิ้น จากนั้นโปรแกรมจะคำนวณราคารวม หากราคารวมมีมูลค่า ตั้งแต่ 500 บาทขึ้นไป จะได้รับส่วนลดทันที 50 บาท หากไม่ถึง 500 บาท จะไม่ได้รับส่วนลด และสุดท้ายให้โปรแกรมแสดงผลราคาสุทธิ ที่ลูกค้าต้องชำระ 1. การวิเคราะห์ปัญหา (Problem Analysis) ข้อมูลเข้า (Input): - ราคาสินค้าต่อชิ้น จำนวนชิ้น กระบวนการ (Process): - ราคารวม = ราคาสินค้าต่อชิ้น * จำนวนชิ้น - ถ้าราคารวมตั้งแต่ 500 บาทขึ้นไป ให้ส่วนลด 50 บาท - ถ้าราคารวมไม่ถึง 500 บาท ให้ส่วนลด 0 บาท - คำนวณราคาสุทธิ = ราคารวม - ส่วนลด ข้อมูลออก (Output): - ราคาสุทธิที่ลูกค้าต้องชำระ 2. เขียนรหัสเทียม (Pseudocode) //เติมคำสั่งให้สมบูรณ์ BEGIN INPUT ราคาสินค้าต่อชิ้น INPUT จำนวนชิ้น COMPUTE ราคารวม = ราคาสินค้าต่อชิ้น * จำนวนชิ้น IF ราคารวม >= 500 THEN COMPUTE ส่วนลด = 50 ELSE COMPUTE ส่วนลด = 0 END IF COMPUTE ราคาสุธิ = ราคารวม - ส่วนลด OUTPUT ราคาสุธิ END 3. เขียนผังงาน (Flowchart) ให้นักเรียนวาดผังงานโดยใช้สัญลักษณ์มาตรฐานที่ถูกต้องตามรหัสเทียมที่ได้ออกแบบไว้ข้างต้น โจทย์สถานการณ์ที่ 2: ระบบตรวจสอบการเข้าใช้งาน (Login System) รายละเอียด: ระบบบริหารจัดการร้านค้าต้องการความปลอดภัย จึงต้องมีระบบ Login ให้ผู้ใช้ป้อน Username และ Password โดยมีเงื่อนไขการตรวจสอบคือ: ถ้า Username คือ "admin" และ Password คือ "12345" ให้แสดงข้อความ "Login Success" แต่ถ้าข้อมูลใดข้อมูลหนึ่งไม่ถูกต้อง ให้แสดงข้อความ "Login Failed" 1. เขียนรหัสเทียม (Pseudocode) //เติมคำสั่งให้สมบูรณ์ BEGIN INPUT Username INPUT Password IF Username = "admin" AND Password = "12345" THEN OUTPUT = "Login Success" ELSE OUTPUT = "Login Failed" END IF END 2. เขียนผังงาน (Flowchart) ให้นักเรียนวาดผังงานโดยใช้สัญลักษณ์มาตรฐานที่ถูกต้องตามรหัสเทียมที่ได้ออกแบบไว้ข้างต้น
